# Roadmap e Evolução

## Fase Atual: Fundação Robusta (v2.0)
*   [x] Motor de descoberta viral com SQLite.
*   [x] Sistema de Fallback Whisper Híbrido.
*   [x] Strategic Audio Sampling (Amostragem estratégica).
*   [x] VPH Relativo e Aceleração de Momentum.

## Próxima Fase: Inteligência Coletiva (v2.5)
*   [ ] **Feedback Loop:** Gravar performance real dos shorts postados.
*   [ ] **Comment Sentiment Analysis:** Analisar a "vibe" da audiência nos comentários.
*   [ ] **Trend Watcher:** Integração automática com Google Trends ou Twitter Trending Topics.

## Fase Avançada: Machine Learning (v3.0)
*   [ ] **Retention Predictor:** Modelo treinado para prever a curva de retenção do YouTube.
*   [ ] **Vector Search:** Embeddings para encontrar conteúdos semanticamente similares que já viralizaram.
*   [ ] **Multi-Modal Analysis:** Primeira camada de análise visual (thumbnails e detecção de rostos/expressões).

## Visão de Longo Prazo
O AutoCut evoluindo de uma ferramenta para um **SaaS de Business Intelligence de Atenção**, onde o usuário não apenas faz cortes, mas recebe insights de quais tópicos estão prestes a explodir em seu nicho.
